# Privacy Policy for 豆瓣读书x浙江图书馆 Extension

## Introduction
This Privacy Policy describes how the "豆瓣读书x浙江图书馆" Chrome extension handles data.

## Data Collection
This extension does not collect, store, or transmit any personal user data. It operates entirely on the client side with the following limited functionality:

1. The extension reads ISBN numbers from Douban Books pages you visit.
2. It makes API requests to Zhejiang Library's catalog (ulib.interlib.cn) to check book availability based on these ISBN numbers.
3. It displays library availability information directly on the Douban book page.

## Data Storage
This extension does not:
- Store personal information
- Use cookies
- Track browsing history
- Collect usage statistics

## Third-Party Services
This extension only communicates with the Zhejiang Library API (ulib.interlib.cn) for the sole purpose of checking book availability. No user data is shared with any third parties.

## Permissions
The extension requires the following permissions:
- Access to "https://ulib.interlib.cn/*" to query the Zhejiang Library catalog
- Access to "https://book.douban.com/subject/*" to insert library availability information on book pages

## Updates to this Policy
This Privacy Policy may be updated from time to time to reflect changes in the extension's functionality. Users will be notified of any significant changes.

## Contact
If you have any questions about this Privacy Policy, please open an issue on the extension's GitHub repository.
